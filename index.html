2. Paste into Outlook


New Outlook for Windows & web
  1. Open Settings → Accounts → Signatures.
  2. Add a signature named Market Recon.
  3. Click in the signature box and paste with Ctrl+V (Windows) or ⌘V (Mac). Keep the source formatting if asked.
  4. Choose it for new messages and, if wanted, replies. Save.


Classic Outlook for Windows
  1. Open File → Options → Mail → Signatures.
  2. Choose New and name it Market Recon.
  3. Paste into the editor with Ctrl+V. Keep source formatting if asked.
  4. Set the defaults for your account. Select Save, then OK.


Outlook for Mac
  1. Open Outlook → Settings → Signatures.
  2. Add a signature and name it Market Recon.
  3. Paste into the editor with ⌘V, then close the editor.
  4. Under Choose which signature appears, select your account and the new-message and reply defaults.


Outlook for iOS & Android
  1. Copy the Mobile text version above.
  2. In the Outlook app, open Settings → Mail → Signature (sometimes shown simply as Signature).
  3. Replace the existing text. Enable Per Account Signature if you use multiple accounts.
  4. Return to your inbox and check a new message.


If copying is blocked: open this page in Chrome, Edge, or Safari. Use Select signature, then Ctrl+C or ⌘C and paste normally. Avoid “paste as plain text” for the three formatted options. If a logo is dropped on paste, insert the included logo in Outlook, or use Essential.
